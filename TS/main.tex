    \section{Цели, задачи и исходные данные}
        \begin{enumerate}[label=\alph*.]
            \item Целью работы является разработка программы для автоматизации учёта продуктиности работы сотрудников на основе выполненных задач (количество, сложность, временные затраты) и расчёта заработной платы с привязкой к ключевым показателям продуктивности (KPI). 
            \item В процессе выполнения работы требуется решить следующие задачи:
                \begin{itemize}
                    \item Провести анализ предметной области (системы оценки продуктивности, KPI, связь продуктивности и оплаты труда).
                    \item Разработать структуры данных для представления информации о сотрудниках, задачах (сложность, ожидаемое время, фактическое время выполнения), ставках оплаты и KPI.
                    \item Реализовать модуль загрузки данных из файлов формата CSV и сохранения результатов.
                    \item Разработать математический аппарат для расчёта: продуктивности выполнения задачи (отношение ожидаемого времени к фактическому с учётом сложности), интегральной продуктивности сотрудника за период (с учётом количества и сложности задач), заработной платы на основе базовой ставки, коэффициента продуктивности и бонусов за перевыполнение, налогов и отчислений (НДФЛ, страховые взносы).
                    \item Создать консольный интерфейс для взаимодействия с пользователем (меню, ввод параметров, вывод отчётов).
                    \item Реализовать систему логирования действий пользователя с временными метками.
                    \item Обеспечить обработку ошибочных ситуаций (отсутствие файлов, некорректные данные, несоответствие форматов).
                    \item Разработать набор тестов (с использованием QuickCheck) для проверки корректности ключевых функций расчёта эффективности и зарплаты.
                    \item Подготовить отчёт по курсовой работе.
                \end{itemize}
            \item Исходными данными для проведения работы являются:
                \begin{itemize}
                    \item Журнал выполненных задач в формате CSV (поля: идентификатор сотрудника, дата, идентификатор задачи, сложность (целое число от 1 до 10), плановое время (часы), фактическое время (часы), результат выполнения (успех/частичный/провал)).
                    \item Справочник сотрудников в формате CSV (поля: табельный номер, ФИО, должность, базовая ставка (руб./час), норма выработки (количество баллов продуктивности в месяц для получения полной ставки)).
                    \item Справочник типов задач с коэффициентами сложности.
                    \item Производственный календарь в текстовом формате (для учёта выходных).
                    \item Конфигурационный файл с параметрами расчёта (базовый KPI, шкала бонусов, ставки налогов).
                \end{itemize}
        \end{enumerate}

    \section{Основные требования к выполнению работы}
        \begin{enumerate}[label=\alph*.]
            \item Разрабатываемый программный комплекс предназначен для автоматизации учёта продуктивности работы сотрудников на основе выполненных задач и расчёта заработной платы с учётом KPI. Программа может использоваться в отделах кадров и бухгалтерии предприятий, внедряющих систему оплаты, зависящую от продуктивности, а также в учебных целях для изучения функционального программирования.
            \item Состав разрабатываемого программного комплекса: 
                \begin{itemize}
                    \item Модуль загрузки данных – чтение файлов (CSV, JSON), парсинг дат/времени, преобразование во внутренние структуры.
                    \item Модуль расчёта продуктивности – вычисление индивидуальной продуктивности по каждой задаче (с учётом сложности, планового и фактического времени).
                    \item Модуль расчёта зарплаты – вычисление заработной платы по каждому сотруднику за выбранный период на основе базовой ставки, коэффициента продуктивности и бонусов.
                    \item Модуль консольного интерфейса – отображение меню, ввод данных, вывод таблиц.
                    \item Модуль логирования – запись действий пользователя в лог-файл.
                    \item Модуль обработки ошибок – функции для безопасной обработки исключительных ситуаций.
                    \item Модуль тестирования – набор модульных тестов и свойств для QuickCheck.
                \end{itemize}
            \item Программное обеспечение должно обеспечить следующие технические характеристики по назначению: 
                \begin{itemize}
                    \item Время загрузки файла объёмом до 10 000 записей – не более 2 секунд.
                    \item Время расчёта продуктивности и зарплаты для 100 сотрудников за месяц – не более 2 секунд.
                    \item Корректная работа под управлением операционных систем семейства Linux, macOS, Windows (при наличии компилятора GHC).
                \end{itemize}
            \item Функциональные требования: 
                \begin{itemize}
                    \item Загрузка данных
                    \item Расчёт продуктивности
                    \item Расчёт заработной платы
                    \item Вывод результатов
                    \item Логирование
                    \item Интерактивное меню
                    \item Обработка ошибок ввода и данных
                \end{itemize}
            \item При разработке математического, программного и информационного обеспечения должны, преимущественно, использоваться типовые и стандартные средства, существующие библиотечные решения.
        \end{enumerate}
